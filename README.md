## Featured Lab: Unit 1

### It Wasn't Me – Insider Threat Investigation

A hands-on network forensics investigation involving suspicious email activity within a simulated corporate environment.

**Tools & Technologies:**
- Wireshark
- SMTP
- PCAP Analysis
- DHCP Logs
- System Security Logs
- Network Forensics

**Investigation Highlights:**
- Analyzed SMTP traffic to identify suspicious email activity.
- Extracted the source IP address from captured network traffic.
- Correlated DHCP records to identify the associated host device.
- Examined security logs to determine the user logged into the device during the incident.
